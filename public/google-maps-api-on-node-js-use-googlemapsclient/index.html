Google maps api on node.js use googleMapsClient

February 12, 2018 · 1 分鐘

原本使用request套件來抓google map api抓資料 結果鬼打牆一直400，在瀏覽器上又可以正確抓到資料 卡了2個小時，改用 googleMapsClient 著個套件一試就成功……. [code language=“javascript”] var googleMapsClient = require(’@google/maps’).createClient({ key: Your_key }); googleMapsClient.places({ query: ‘台北市 故宮博物院’ }, function(err, response) { if (!err) { console.log(response.json.results); } }); [/code]
