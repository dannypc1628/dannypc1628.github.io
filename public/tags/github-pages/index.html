    將十年老 WordPress 部落格搬遷至 Hugo + GitHub Pages：從 Ubuntu 14.04 到免費靜態網站的完整紀錄

    十年前還在大學的時候，為了學習 Linux、PHP 與網站架設，我在 DigitalOcean 租了一台 VPS，自己安裝 Ubuntu、Apache、MySQL 和 WordPress，架設了個人技術部落格 dannyliu.me。 當年的自己應該沒想到，這台伺服器竟然會一直運作到 2026 年。🤣 隨著工作越來越忙，部落格逐漸荒廢，作業系統、PHP、WordPress 及外掛也很久沒有更新。 最近看到一些 PHP 和 WordPress 的資安議題，突然想到自己還有一台十年沒認真維護的伺服器，決定趁這個機會重新整理網站。 原本只是打算更新 WordPress，沒想到最後直接把整個網站從動態架構搬到 Hugo + GitHub Pages。 這篇文章記錄完整的搬遷過程、遇到的問題，以及最後的處理方式。 用 Wayback Machine 看 2018 年的首頁還是用中美堂的照片 那時候還在當兵，後來才換成現在 Bootstrap 的版型。 看第一篇文章發布日期是 2016-03-24 這個部落格是真的有 10 年了 🤣 一、原本的 WordPress 環境有多古老？ 先透過 SSH 登入 DigitalOcean Droplet，確認目前環境。 Ubuntu 與 Kernel cat /etc/os-release uname -a 查詢結果： 項目 舊環境 作業系統 Ubuntu 14.04.6 LTS Linux Kernel 3.13.0-79-generic PHP 7.0.33 Apache 2.4.7 MySQL 5.5.62 WordPress 5.8.2 RAM 1 GB Disk 25 GB 其中 Ubuntu 14.04 發布於 2014 年，標準安全維護早已結束；PHP 7.0 和 MySQL 5.5 也都已停止正常安全支援。 ...
