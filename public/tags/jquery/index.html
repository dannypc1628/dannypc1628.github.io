Vue.js jQuery在IE 11使用中文輸入法的小問題

在學Vue.js時，真的覺得Vue.js操作起來很方便 之前寫的ToDoList專案中，遇到在IE11使用中文輸入法選字時，按Enter會觸發新增事項的method < input v-model="newToDo" v-on:keyup.enter="addToDo" class="form-control" placeholder="新增事項" /> keyup是偵測放開按鍵時的事件，在Chrome跟Firefox上都正常，就是IE有問題真的昏倒 好險改用keypress就正常了 <input v-model="newToDo" v-on:keypress.enter="addToDo" class="form-control" placeholder="新增事項" /> 這問題查了一下在jQuery或原生JavaScript也有 所以這應該是IE的js引擎有bug吧!? JavaScript跟jQuery一樣改成keypress就好，例如: <!-- JavaScript --> &nbsp <input type="text" onkeypress="addToDo()"> <!-- jQuery --> $('#inputText').bind('keypress', function (event) { &nbsp if (event.keyCode == 13) &nbsp { &nbsp &nbsp addToDo(); &nbsp } }); 補充：keypress是按的過程中觸發，所以一直按住就會一直觸發，而keyup只會在放開按鍵時觸發一次
