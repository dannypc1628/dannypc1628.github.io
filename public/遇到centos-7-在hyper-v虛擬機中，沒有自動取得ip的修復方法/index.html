遇到CentOS 7 在Hyper-V虛擬機中，沒有自動取得IP的修復方法

August 19, 2018 · 1 分鐘

我在 Windows Server 201 6中用 Hyper-V 虛擬機裝 CentOS 7.5 遇到沒有網路的小問題 在 Linux 上，習慣會用 ipconfig 來看有沒有拿到IP 輸入進去後，bash居然回應說沒有ipconfig這個指令臉還小囧一下 原來CentOS 要改用 ip address 來查自己的ip 查完可以看到 lo本機網路ip是127.0.0.1 但是 eth0連外網路卻沒跟我路由器上的DHCP自動取得IP 重新開機也沒有抓成功，google一下也沒馬上找到解答，可能不是常見的問題!？ 最後在這篇文章提到解法，但討論串上看起來還不曉得發生問題的確切原因 https://mangolassi.it/topic/9223/centos-7-vm-on-hyper-v-losing-dhcp-assigned-address 使用 ifdown eth0 關閉eth0 再用 ifup eth0 重新啟動eth0 果真成功拿到ip……..
