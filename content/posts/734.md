在寫asp.net時順手把cookie設定成Secure，想說偵錯模式時就改用Https來連線，一波三折就生出這篇文章。

我今天使用的是Visual Studio 2017 15.9.18，使用內建的IIS Express進行偵錯，預設.NET Core是有啟動HTTPS的，但.NET Framework則無。另外，要啟動Https的話在.NET Core中與.NET Framework兩者設定方式是不一樣的。另外還有IIS Express的`SSL port`要注意。

# ASP.NET Core

net core是從方案總管，點選專案名稱按`右鍵`，接著點選`屬性` ![](/wp-content/uploads/2020/01/螢幕擷取畫面-33.png)

來到屬性設定頁左側，點選`偵錯`，再至Web伺服器設定勾選`啟用SSL` ![](/wp-content/uploads/2020/01/螢幕擷取畫面-34.png)

# .NET Frameowrk ASP.NET MVC

.net Framework是點選專案名稱後，至屬性視窗啟用SSL設為`True` ![](/wp-content/uploads/2020/01/螢幕擷取畫面-35.png)

# 屬性視窗的啟用方式

左上角點選`檢視`，再點選`屬性視窗` ![](/wp-content/uploads/2020/01/螢幕擷取畫面-37.png)

# IIS Express的SSL Port

IIS Express要啟動Https的話已經不需要以系統管理員的身分執行Visual studio，但是SSL Port已經鎖定在`44300 到 44399`這個區間port號才能使用，若手動更改成這個區間以外的port將會無法啟動。
